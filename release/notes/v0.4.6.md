# Spine CLI v0.4.6

## v0.4.6-preview.1

Generated applications and static contract inspection support the new HTTP, WebSocket and event contexts, application-provided publishers and senders, and preview shutdown hooks.

- HTTP handlers keep `spine.Ctx` and access shared values through `ExecutionContext()`. HTTP inspection rejects message contexts.
- Message generators inspect the selected core source, including local replacements. When available, consumers use `spine.EventCtx` and WebSocket handlers use `spine.WebSocketCtx`. Older core contracts retain their supported generation forms.
- WebSocket generation uses controller registration, `r.WS`, `input.Message[T]` and DI-managed `ws.Sender`. Contract inspection resolves context aliases and rejects contexts from another transport.
- The synchronous `publish.Publisher` is an application-owned DI dependency. Inspection rejects user constructors for that reserved interface. Broker fixtures select the publishing API supported by their installed core.
- Generation dependency checks recognize the installed application-owned publisher and sender contracts without requiring user providers.
- Static HTTP and WebSocket adapter inspection recognizes `WithShutdownHook` without executing the hook or its dependencies.
- Imported event subscription constants are resolved from source, including with Go 1.27. Source-candidate coverage checks constructor errors, shutdown-hook DI, publishing and conditional OpenAPI export.
- Generated Kafka, RabbitMQ and NATS preview applications verify destination configuration. Missing destinations select consume-only operation, and blank destinations are rejected.

Local validation covers race tests, static checks, both generated layouts, HTTP public views, local WebSocket send/receive, and event ACK/NACK through an in-memory adapter. The full regression run was completed in segments after its time limit; a transient module-resolution timeout passed on retry. Real broker E2E and minimum-toolchain release gates require their configured environments. Source-candidate tests do not establish public installation support for an unreleased core.
