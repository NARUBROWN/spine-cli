# Spine CLI v0.4.6

## v0.4.6-preview.1

Spine 프리뷰 앱에서 `WithShutdownHook`를 등록하면 `spine verify`가 어댑터를 확인할 수 없다고 판단하던 문제를 수정합니다.

- HTTP와 WebSocket 어댑터 정적 검사는 `spine.WithShutdownHook(callback)`을 인식합니다. 콜백과 DI 의존성을 실행하지 않고 옵션 형식만 확인합니다.
- 이벤트 구독에 사용한 다른 패키지의 문자열 상수는 소스와 의존성을 읽어 해석합니다. Go 1.27에서 기존 분석 라이브러리가 컴파일된 타입 정보를 해석하지 못하던 문제를 해결합니다.
- 프리뷰 코어의 생성자 `error` 반환, 종료 훅 DI 주입, `publish.Event(ctx, destination, publish.Fields{...})`, `publish.DomainEvents`와 조건부 OpenAPI의 런타임 내보내기를 회귀 검사합니다.
- Kafka, RabbitMQ와 NATS 프리뷰 모듈로 생성한 앱에서 발행 목적지 설정과 `verify`를 검사합니다. 목적지 목록이 없으면 소비 전용으로 설정하고, 목록 안의 빈 항목은 거부합니다. 이 검사는 실제 브로커 연결이나 송수신을 확인하지 않습니다.
