# Spine CLI v0.4.5

이 버전은 기존 Cloud Preview에서 검증한 CLI 변경을 이어갑니다.

- `spine cloud auth login`, `status`, `logout`으로 Cloud 세션을 관리합니다.
- `spine deploy`로 Spine 프로젝트를 빌드하고 Cloud에 배포합니다. `--app`으로 기존 앱을 지정할 수 있습니다.
- 앱 이름 중복, 계정 한도, 배포 접수 및 실행 오류에 대해 Cloud가 제공한 안내를 표시합니다.
- Spine 코어의 명시적 HTTP 입력 계약을 검사하고, 해당 계약을 사용하는 프로젝트의 생성 코드에 입력 래퍼를 적용합니다.

기존 Cloud Preview 태그와 변경 이력은 [v0.4.4 Preview 기록](./v0.4.4.md)에서 확인할 수 있습니다.
