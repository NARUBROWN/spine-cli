# Spine CLI v0.4.5

## v0.4.5-preview.1

Spine 코어의 명시적 HTTP 입력 계약에 맞춰 정적 검사와 생성 코드를 정비합니다. 기존 Cloud Preview의 인증과 배포 명령도 유지합니다.

- `input.Body[T]`, `input.Path[T]`, `input.Query[T]`, `input.Header[T]`를 일관되게 검사합니다. Body DTO의 익명 포인터 임베딩과 로컬 및 외부 타입 alias를 해석하고, 상대 `replace` 경로는 원래 프로젝트를 기준으로 조회합니다.
- 선택한 코어 버전에 맞춰 XML 필드 경로 충돌과 여러 HTTP 응답 반환값을 검사합니다. 헤더 목록, 제네릭 입력과 응답, WebSocket 핸들러 검사도 코어 계약에 맞춥니다.
- 최신 코어를 대상으로 하는 컨트롤러와 메시지 핸들러에는 현재 API를 생성합니다. WebSocket과 이벤트 핸들러는 지원되는 코어에서 `spine.Ctx`를 사용합니다.
- `g route`는 `api.Registry`가 지원하지 않는 HTTP 메서드를 파일 변경 전에 거부합니다. Path DTO가 경로 변수 일부만 사용하는 경우는 허용하며, 스칼라 Path 입력 개수 검사는 유지합니다.
- Go import 경로로 사용할 수 없는 그룹 이름은 파일 생성 전에 거부합니다. 유효한 중첩 그룹과 Unicode 타입 및 파일 이름은 계속 지원합니다.

- `spine cloud auth login`, `status`, `logout`으로 Cloud 세션을 관리합니다.
- `spine deploy`로 Spine 프로젝트를 빌드하고 Cloud에 배포합니다. `--app`으로 기존 앱을 지정할 수 있습니다.
- 앱 이름 중복, 계정 한도, 배포 접수 및 실행 오류에 대해 Cloud가 제공한 안내를 표시합니다.

기존 Cloud Preview 태그와 변경 이력은 [v0.4.4 Preview 기록](./v0.4.4.md)에서 확인할 수 있습니다.
