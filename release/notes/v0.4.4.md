# v0.4.4-preview.4 Spine Cloud 배포 기기 식별값

`spine deploy`는 공식 Spine Cloud API에 배포할 때 네트워크 어댑터의 MAC 주소를 해시한 식별값을 보냅니다. Spine Cloud는 이 값으로 기기 단위 배포 제한을 적용할 수 있습니다. MAC 주소 원문은 기기 밖으로 보내지 않으며, 사용자 지정 API에는 식별값을 보내지 않습니다.

# v0.4.4-preview.3: Spine Cloud 오류 메시지 전달

관리 API가 제공하는 사용자용 오류 메시지를 CLI에 표시합니다. 계정의 앱 한도와 앱 이름 중복을 구분하고, 배포 접수와 실행 중 발생한 오류의 안내도 표시합니다. 이전 관리 API의 오류 응답과 알려진 배포 실패 사유는 계속 지원합니다.

표시 메시지의 길이를 제한하고 터미널 제어 문자를 거부합니다. 이 버전은 Preview 후보이며 공개 설치 검증은 발행 후 진행합니다.

# v0.4.4-preview.2: Spine Cloud 배포 명령

`spine deploy`로 프로젝트의 정적 계약을 검사하고 Linux ARM64 실행 파일을 빌드해 Spine Cloud에 제출합니다. 프로젝트에 대응하는 앱을 찾거나 만들고, 배포 성공 여부를 확인합니다. `--app`으로 기존 앱을 지정할 수 있습니다. 프론트엔드 정적 파일 배포는 아직 지원하지 않습니다.

호스트 CPU 또는 메모리 부족으로 배포가 거부되거나 자원 측정이 불가능하면 해당 사유와 재시도 안내를 표시합니다. 다른 배포 실패는 대시보드 확인을 안내합니다.

발행 전 후보이며 실제 서비스 배포와 공개 설치 검증은 아직 완료하지 않았습니다.

# v0.4.4-preview.1: Spine Cloud 인증

`spine cloud auth login`으로 브라우저에서 일회용 코드를 승인하고 세션을 운영체제 자격 증명 저장소에 보관합니다. `spine cloud auth status`는 현재 계정을 확인하고 필요하면 세션을 갱신합니다. `spine cloud auth logout`은 현재 세션을 서버에서 폐기한 뒤 저장된 자격 증명을 삭제합니다. 다른 기기의 세션은 유지됩니다.

이 버전은 Preview 후보입니다. 실제 서비스와 브라우저를 연결한 인증 흐름과 공개 설치 검증은 아직 완료하지 않았습니다.

## 다중 스칼라 Path 지원 버전 정정

다중 스칼라 `input.Path`의 최소 코어 버전을 실제 수정이 포함된 `v0.7.1`로 정정합니다. `v0.7.0`과 그 이전 Preview, RC는 오류로 거부합니다. `v0.7.1`의 사전 릴리스와 교체한 로컬 코어는 정적 분석만으로 지원 여부를 확정하지 않고 경고합니다. 단일 스칼라 입력의 최소 버전은 유지합니다.
