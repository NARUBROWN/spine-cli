# Spine CLI v0.4.4

Spine 코어 `v0.7.5`의 명시적 HTTP 입력을 검사하고 생성하는 핫픽스입니다. 새 HTTP 프로젝트의 기본 채널에서 코어 `v0.7.5`와 Echo 플랫폼 `v0.2.1` 조합을 검증합니다.

## 주요 변경

- 명시적 계약을 사용하는 프로젝트에서 래퍼 없는 포인터 DTO 인자를 진단합니다.
- `input.Body[T]`의 본문과 폼 입력을 검사하고 OpenAPI에 반영합니다.
- `input.Header[T]`의 헤더 입력을 검사하고 OpenAPI에 반영합니다.
- 생성기가 프로젝트의 코어 버전에 맞춰 경로와 본문 인자에 `input.Path[T]`, `input.Body[T]`를 사용합니다.

## 설치

Go `1.25.5` 이상에서 다음 명령을 실행하세요.

```sh
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.4
spine version
```
