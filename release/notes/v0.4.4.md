# v0.4.4-preview.1: Spine Cloud 인증

`spine cloud auth login`으로 브라우저에서 일회용 코드를 승인하고 세션을 운영체제 자격 증명 저장소에 보관합니다. `spine cloud auth status`는 현재 계정을 확인하고 필요하면 세션을 갱신합니다. `spine cloud auth logout`은 현재 세션을 서버에서 폐기한 뒤 저장된 자격 증명을 삭제합니다. 다른 기기의 세션은 유지됩니다.

이 버전은 Preview 후보입니다. 실제 서비스와 브라우저를 연결한 인증 흐름과 공개 설치 검증은 아직 완료하지 않았습니다.
