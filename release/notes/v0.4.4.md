# Spine CLI v0.4.4 HTTP 입력 핫픽스

Spine 코어 `v0.7.2-rc.1`의 명시적 HTTP 입력 계약을 CLI에서 검사하고 생성합니다.

- 명시적 계약을 사용하는 프로젝트에서 래퍼 없는 포인터 DTO 인자를 진단합니다.
- `input.Body[T]`의 본문과 폼 입력을 검사하고 OpenAPI에 반영합니다.
- `input.Header[T]`의 헤더 입력을 검사하고 OpenAPI에 반영합니다.
- 생성기가 프로젝트의 코어 버전에 맞춰 경로와 본문 인자에 `input.Path[T]`, `input.Body[T]`를 사용합니다.

이 후보는 Cloud 기능을 제외한 HTTP 입력 핫픽스입니다.
